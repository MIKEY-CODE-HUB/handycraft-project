# HandyCrafts

A responsive React and Vite storefront built around the original dark homepage, ship-in-a-bottle hero, and seasonal collections.

## Run locally

Use Node.js 22.12 or newer.

```sh
npm ci
npm run dev
```

Run `npm run build` for the production site and `npm run preview` to preview the build. Publish the `dist/` directory to a static host. Hash routes keep collections, search results, and product links available on refresh without server rewrites.

## Try the storefront

1. Open **Gift Finder** and choose **Wedding**, **₹1,000–₹2,000**, and **Keepsakes**.
2. Open **Blooming Love Gift Set**. Enlarge the photo, save the product, and add it to the basket.
3. Change the basket quantity, refresh, and reopen the basket and favourites.

Favourites and basket quantities are stored in the current browser. The catalog is a demo, the added listings use generated product imagery, and checkout is unavailable. The original HTML pages remain in the source tree for reference.
